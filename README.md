# Neon Crime Roadbook

Build the foundation of GTA VI Guide



I am building a professional, SEO-focused gaming website called GTA VI Guide.



The website will become a comprehensive independent fan-made Grand Theft Auto VI encyclopedia, map and walkthrough platform.



The primary goal is to attract organic traffic from Google for searches such as:



- GTA 6 vehicles

- GTA 6 car locations

- GTA 6 vehicle list

- GTA 6 map

- GTA 6 missions

- GTA 6 cheats

- GTA 6 weapons

- GTA 6 collectibles

- GTA 6 locations

- GTA 6 guides



1. First inspect and plan



Before implementing anything:



- Inspect the existing project and identify its framework.

- Keep the existing framework if one is already configured.

- Propose a clean, scalable architecture.

- Prioritize server-rendered or statically generated public pages wherever supported.

- Make sure important page content is available in crawlable HTML, not dependent entirely on client-side JavaScript.



2. Design direction



Create a premium gaming encyclopedia aesthetic:



- Dark charcoal and black backgrounds.

- White text with restrained neon pink and cyan accents.

- High-quality gaming imagery.

- Modern typography.

- Professional cards and content layouts.

- Excellent mobile, tablet and desktop responsiveness.

- Avoid generic AI-generated website aesthetics.



Brand name: GTA VI Guide.



Do not use Rockstar's official logo or imply that this website is affiliated with Rockstar Games.



3. Main website architecture



Prepare the following public routes:



- /

- /map

- /vehicles

- /vehicles/[slug]

- /missions

- /missions/[slug]

- /locations

- /locations/[slug]

- /weapons

- /weapons/[slug]

- /cheats

- /collectibles

- /characters

- /guides

- /news

- /about

- /contact

- /privacy-policy

- /terms

- /disclaimer



Use clean, readable and SEO-friendly URLs.



4. SEO foundation



Implement the technical SEO architecture from the beginning:



- Unique page title and meta description for every indexable page.

- Semantic HTML with one clear H1 per page.

- Canonical URLs.

- XML sitemap.

- robots.txt.

- Open Graph and social sharing metadata.

- Breadcrumb navigation.

- Descriptive image alt text.

- Internal linking between related content.

- Appropriate structured data where eligible.

- Custom 404 page.

- Proper redirects and no duplicate URLs.

- Fast page loading and optimized images.



Do not create fake keywords, fake ratings, fake facts or empty SEO pages.



5. Content accuracy



GTA VI information must be treated carefully.



Every content record should support these statuses:



- Officially confirmed

- Independently verified in-game

- Reported but unverified

- Speculation

- Not yet discovered



Never invent vehicles, vehicle spawn locations, missions, cheats, collectibles, weapons or gameplay details.



Before release, publish only information supported by official material or reliable evidence. After release, allow verified in-game discoveries to be added.



6. Website access



- No public registration.

- No public visitor accounts.

- All published content must be accessible without login.

- Prepare the architecture for a secure private administrator/editor dashboard later.

- Visitors must not be able to modify website content.



7. Development requirements



- Reusable components.

- Maintainable code.

- Scalable content architecture.

- Accessible navigation.

- Good performance on mobile devices.

- Search-engine crawlability.



For now, implement only the project foundation and explain the architecture. Do not attempt to generate every section in one step.



I will provide additional prompts for the homepage, vehicles, interactive map, missions, database and other sections separately.
